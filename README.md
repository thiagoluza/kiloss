# kiloss

Projeto pessoal de acompanhamento de treinos e saúde. Um app web simples, focado em mobile, que funciona offline.

## O que faz

- **Treinos** — cria e gerencia planos de treino com exercícios
- **Progresso** — registra exercícios e acompanha recordes pessoais (PRs)
- **Hidratação** — controla a ingestão de água diária
- **Peso** — registra e visualiza a evolução do peso ao longo do tempo

## Tecnologias

- JavaScript vanilla (ES6 modules)
- CSS puro
- localStorage para persistência dos dados
- PWA com suporte offline via Service Worker

## Como rodar

Basta abrir o `index.html` no navegador ou servir a pasta com qualquer servidor estático.
